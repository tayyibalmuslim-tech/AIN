## الحالة الحالية
- `index.html` مكتمل ويعرض كل الحلقات كقائمة بتصميم "الطريق" (من الظلمة للنور).
- كل ملف داخل `steps/` **فارغ حاليًا (placeholder)** — فيه بس العنوان والهوية البصرية، جاهز إنك تضيف المحتوى جواه وقت ما يكون متاح عندك.

## طريقة رفعه على GitHub
1. اعمل repository جديد على GitHub (مثلاً باسم `ain-altareeq`).
2. من جهازك، داخل مجلد المشروع نفّذ:
```bash
git init
git add .
git commit -m "الهيكل الأساسي لسلسلة أين الطريق"
git branch -M main
git remote add origin https://github.com/USERNAME/ain-altareeq.git
git push -u origin main
```
3. لو حابب تفعّل GitHub Pages عشان يبقى فيه رابط مباشر للموقع:
   Settings → Pages → اختار branch `main` واحفظ.

## إضافة محتوى حلقة لاحقًا
افتح ملف الحلقة اللي عايز تضيفها، وهتلاقي داخل `<main>` صندوق باسم `placeholder` — استبدله بمحتوى الحلقة الفعلي، والتصميم (الألوان والخطوط والتنقل) هيفضل زي ما هو تلقائيًا.
